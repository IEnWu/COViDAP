# COViDAP

COViDAP is a web tool for determining a given molecule’s drug activity against SARS-CoV-2 and its conformity with known drug behavior based on five drug-likeness tests.

How to Use COViDAP:
Enter the SMILES notation of the molecular candidate.
Click the “Submit” button to generate the candidate’s report.
Receive the molecule’s predicted activity against SARS-CoV-2 and its conformity to known drug-likeness criteria.
A SARS-CoV-2 drug candidate must be predicted to be active and pass all five drug-likeness tests.

Report - 
Canonical SMILE
Molecular Formula
Predicted Activity Against SARS-CoV-2: Active/Inactive
Drug Likeness: Pass/Fail
